# TSERB Assessment Development Blueprint

Version: 1.0

## Objective

This blueprint defines how Tiny Steps should develop the **actual assessment instruments** used with the Tiny Steps Early Reading Benchmark (TSERB). The School Partnership Portal stores and reports the resulting aggregate evidence; it does not make an assessment valid merely by calculating scores correctly.

The development sequence is intentionally conservative so Tiny Steps can first operate a high-quality internal programme benchmark and later decide whether independent psychometric validation/norming is commercially justified.

## 1. Intended use statement

Every TSERB form and scoring guide should state the intended use before item development begins.

Current intended uses:

- establish an instructional starting point for Tiny Steps school implementation;
- identify broad foundational-reading strengths and support needs;
- monitor section-level progress across defined checkpoints;
- inform Learning Partner coaching and intervention planning;
- give school leadership transparent aggregate evidence.

Current excluded uses:

- diagnosis;
- admissions/selection;
- grade retention/promotion decisions;
- reading-age claims;
- high-stakes teacher evaluation;
- internationally normed percentile claims;
- comparison of schools as a league table.

## 2. Construct map

TSERB should measure only constructs that Tiny Steps can define and administer consistently.

### Domain A — Phonological awareness

Candidate constructs:

- rhyme awareness where instructionally relevant;
- initial/final phoneme awareness;
- oral blending;
- oral segmentation;
- selected phoneme manipulation for advanced learners.

Avoid making print knowledge a hidden requirement for an oral phonological-awareness item.

### Domain B — Grapheme–phoneme / sound knowledge

Candidate constructs:

- recognition of explicitly taught graphemes;
- production of accepted target phoneme(s);
- selected alternative spellings only after instruction.

Items should be presented in mixed rather than teaching order.

### Domain C — Blending and decoding

Candidate constructs:

- VC/CVC decoding;
- digraph decoding;
- consonant blends;
- long-vowel / vowel-pattern decoding;
- increasingly complex taught patterns;
- multisyllabic decoding where instructionally appropriate.

Use unfamiliar controlled words so recall of a memorised class word list does not substitute for decoding.

### Domain D — Pseudoword decoding

Use only where developmentally and instructionally appropriate. Pseudowords help test application of taught grapheme–phoneme knowledge without lexical memorisation, but must:

- be pronounceable;
- contain only intended/taught code for that form;
- avoid accidental offensive/real-word associations across likely school languages where practicable;
- be scored with accepted pronunciation variants defined in the scoring guide.

Pseudoword performance is evidence within decoding, not a separate “intelligence” measure.

### Domain E — Segmenting, encoding and spelling

Candidate constructs:

- phoneme segmentation;
- mapping phonemes to taught graphemes;
- encoding controlled regular words;
- later application of taught spelling patterns.

Do not score an untaught orthographic convention as though it had already been taught.

### Domain F — Connected-text reading

Candidate constructs for learners who have reached this stage:

- reading accuracy;
- appropriate automaticity;
- phrasing/prosody observations;
- persistence with decoding instead of guessing;
- literal understanding of independently accessed text.

Text must be instructionally controlled/aligned. Do not call a passage “age appropriate” as though TSERB has established age norms.

### Domain G — Comprehension

Keep comprehension demands proportionate to the text the child can independently decode. If a child cannot access the text, the result should not be interpreted as a clean measure of reading comprehension.

For multilingual/EAL learners, avoid unnecessary rare vocabulary/cultural knowledge when those are not the intended constructs.

## 3. Adaptive administration model

Ages 3–6 span very different reading stages. One fixed long test is inefficient and can be inappropriate.

Use a **stage-based routing model**.

### Entry route 1 — Pre-reader / emerging code knowledge

Focus on:

- oral phonological awareness;
- taught sound knowledge;
- supported/early blending where ready.

Stop before advanced print tasks when the prerequisite skill is clearly not established.

### Entry route 2 — Early decoder

Focus on:

- mixed taught sound knowledge;
- unfamiliar regular word decoding;
- selected pseudowords where appropriate;
- segmenting/encoding;
- simple controlled sentence reading if ready.

### Entry route 3 — Developing independent reader

Focus on:

- increasingly complex taught decoding patterns;
- encoding/spelling;
- controlled sentences/passages;
- fluency/accuracy observation;
- comprehension on independently accessed text.

Routing rules must be explicit in the assessor guide so two assessors do not choose different difficulty paths based only on intuition.

## 4. Time burden target

The benchmark should minimise instructional disruption.

Recommended design objective:

- keep 1:1 oral/reading administration short and purposeful;
- use small-group or classroom-compatible tasks only where the construct can still be scored reliably;
- avoid extending an assessment merely to create more data;
- record actual pilot administration times before publishing a promised duration.

Do not advertise a precise number of minutes until timing has been verified in real school pilots across learner stages.

## 5. Equivalent form architecture

At minimum develop controlled form families rather than repeatedly presenting the exact same items.

Example structure:

- Baseline Form A
- Checkpoint Form B
- Mid Form C
- Final Form D
- Recovery/Custom Form E where needed

Forms should be constructed to be comparable in:

- taught-code coverage;
- item format;
- approximate difficulty;
- number of opportunities per critical skill;
- vocabulary familiarity/cultural loading;
- passage length/decodability at relevant stages.

Equivalent does not mean identical.

## 6. Item-bank metadata

Every controlled item should have internal metadata such as:

- item ID;
- form/version;
- domain;
- intended TS instructional band;
- graphemes/patterns required;
- word type: real/pseudoword;
- instruction prerequisite;
- accepted response(s)/pronunciation variants;
- scoring rule;
- language/cultural review note where relevant;
- pilot item statistics when available;
- retired/active status.

Do not expose item-bank metadata or scoring keys in the school management portal.

## 7. Scoring architecture

### Item-level scoring

Use the simplest scoring that preserves evidence quality, typically correct/incorrect plus narrowly defined error coding where it will genuinely improve instruction.

Avoid subjective multi-point scoring unless assessor examples and moderation support it.

### Domain scores

Domain scores should reflect the items actually administered. If a domain was not appropriate for the learner/stage, report it as not assessed rather than zero.

### TS instructional level

A TS level should be determined by critical skill evidence and independence criteria defined in the scoring guide, not solely by averaging every task.

### Section-level average

The portal’s weighted average TS level is a section communication summary calculated from the distribution of assigned TS levels. It is not an interval-scale claim and should not be interpreted as though a move from TS-2 to TS-4 is psychometrically identical to a move from TS-6 to TS-8.

This limitation should be considered when discussing “TS-level growth”.

## 8. Important scale limitation

TS-0…TS-9 currently functions as an **ordered instructional scale**. Until empirical evidence supports stronger measurement assumptions:

- treat individual TS levels primarily as ordered descriptors;
- use distribution shifts and domain evidence alongside the average;
- do not imply equal distance between every pair of levels;
- do not translate TS differences into months/years of reading growth;
- avoid over-precision in leadership interpretation.

The portal may display an average for concise management communication, but the distribution and domain evidence remain essential context.

## 9. Fairness review

Before an item enters a live form, review for:

- unnecessary dependence on culturally specific knowledge;
- vocabulary demands unrelated to the target construct;
- ambiguous pictures or prompts;
- accent/pronunciation assumptions;
- EAL/multilingual accessibility;
- visual/accessibility barriers;
- accidental real-word/offensive meaning in likely learner languages for pseudowords;
- bias introduced by examples or names where avoidable.

Fairness review should include people familiar with multilingual early-years learners, not only the item author.

## 10. Administration standardisation

Create a short assessor script for each task covering:

- exact task instruction;
- permitted practice item;
- permitted repetition;
- permitted prompt;
- when prompting makes the item unscored/incorrect;
- accepted pronunciation variants;
- stop/routing rule;
- how to record no response;
- how to record not assessed;
- accommodation documentation.

## 11. Assessor calibration and moderation

Before each formal pilot/rollout:

1. assessors review the scoring guide;
2. assessors score common examples;
3. disagreements are discussed before live testing;
4. a sample of live assessments is independently rescored or double-scored;
5. ambiguity is logged;
6. scoring guidance is revised under a new controlled version when necessary.

Do not invent a reliability percentage and call it validated before sufficient data exists.

## 12. Pilot evidence programme

### Stage 1 — Content/face review

Use Tiny Steps curriculum experts and external early-literacy/assessment review where feasible to check:

- construct coverage;
- instructional alignment;
- developmental appropriateness;
- clarity;
- cultural/language fairness;
- scoring rules.

### Stage 2 — Operational pilot

Across several genuine classrooms/schools, collect:

- administration time;
- missing/no-response patterns;
- item difficulty patterns;
- assessor disagreement;
- learner engagement/frustration indicators;
- floor/ceiling effects;
- form-specific anomalies;
- EAL/multilingual observations.

### Stage 3 — Form-equivalence study

Before strong growth claims, evaluate whether different forms are sufficiently comparable for the intended checkpoint use. Revise/retire problematic items.

### Stage 4 — Measurement-quality study

With a qualified assessment/psychometric partner, evaluate evidence relevant to intended score use, including reliability/consistency, fairness and validity.

### Stage 5 — Norm/reference study only if commercially needed

If Tiny Steps later wants age/grade percentiles or international/national normative interpretations, commission a separate representative/reference-sample design appropriate to those claims. Sample composition and size should be determined by the intended inference and psychometric design—not by a marketing target.

## 13. Data required for future validation

The current portal intentionally stores section aggregates. That is appropriate for low-burden implementation but is insufficient by itself for detailed item-level psychometric analysis.

For a future validation study, collect item-level de-identified/research data under a separately approved protocol with:

- clear purpose;
- school agreement/consent requirements as applicable;
- data minimisation;
- pseudonymous study IDs rather than unnecessary identity data;
- form/item identifiers;
- administration context;
- relevant language/access variables only where justified;
- retention/deletion controls;
- qualified research/psychometric oversight.

Do not silently repurpose routine school-portal data into a research dataset.

## 14. International benchmarking pathway

### What Tiny Steps can achieve now

**Internationally informed internal programme benchmarking**:

- common TSERB constructs;
- common administration/scoring protocol;
- versioned equivalent forms;
- multilingual/access fairness controls;
- school-level baseline and repeat checkpoints;
- transparent management reporting;
- moderation across assessors.

### What requires later evidence

**Internationally normed benchmarking**:

- defined reference population(s);
- cross-country/cross-context sampling;
- item/form measurement evidence;
- fairness/differential-performance investigation;
- reliability and validity evidence for intended interpretations;
- defensible standard-setting or normative reporting method;
- independent expert/psychometric review.

The product roadmap must keep these two stages separate.
