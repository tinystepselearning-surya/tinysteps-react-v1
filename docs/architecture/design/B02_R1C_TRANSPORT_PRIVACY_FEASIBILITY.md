## 2. Decision

Reject high-level getAll/select/get or stream as the sole enforcement boundary for a strict zero-retry/cancellable transport: masks are supported but hidden retries and lack of documented per-call control invalidate that inference. Do not change the existing production SDK or canonical logic. Evaluate the generated v1 streaming API using exact locked resolution as first candidate; only use documented public exports, no dependency edits or private method monkeypatch in production. Alternative: explicit single-attempt REST HTTPS batchGet/runQuery with fixed origin, no redirects or automatic retry, AbortSignal covering headers and body, bounded streaming parser and externally observed request counts. Neither route is accepted yet. Local cancellation cannot guarantee server-side processing or billing ceased; record ambiguous outcomes. If neither can meet measured requirements, HOLD rather than weakening gate.

## 4. Budget and failure semantics

Inherited proposed cap: 10 actors, 7 logical operations per actor, 70 total; 5 point slots + 2 x 51 query slots = 107 per actor, 1,070 total. Separate browser verification proposal 20 reads, not part of this lane. Reserve worst-case slots before every dispatch; never refund on uncertain failure. Track planned/reserved/dispatched/completed/cancelled/unknown transport calls and returned docs separately; reconcile transport attempts to logical operations, including any automatic retries. A single-point RPC or query RPC for each descriptor, no retries, no pagination, no speculative prefetch; cap concurrency at the two canonical queries (parallel dispatch may already be in flight). After first blocker stop new dispatch, cancel all active calls, drain terminal events and discard late results; no partial PASS. Local terminal drain is not proof of backend completion. Empty query minimum billing and possible reads on failed/cancelled requests mean 1,070 slots is not an independently proven billing maximum. Measure usage separately under a later approved plan; no claim of zero or exact billed reads. Proposed prototype ceilings (not approved production values): 5 seconds per RPC, 30 seconds per actor, 5 minutes for lane, bounded cancellation drain 2 seconds; use monotonic elapsed time plus wall-clock approval expiry, whichever closes first. Test timers and cancellation at every stage; unknown outcome blocks further work. No automatic scheduled repeat.
