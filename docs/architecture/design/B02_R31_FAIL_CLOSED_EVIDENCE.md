## Contract and decisions

- One provider instance retains exactly one immutable request/actor/operation binding and positive snapshot. Separate fixture operator capability is the stipulated authoritative source; consumer receives only evaluate(request, actor), with no clock or revision argument, no evidence/receipt/data and no mutation permission. Actor still a synthetic caller assertion, NOT authenticated identity.
- Publish validates the binding separately from positive evidence. Valid unrelated binding is rejected without affecting this instance. Older revisions are delayed publications and cannot roll back state. Same-revision exact canonical duplicate is a no-op; conflicting content closes. A newer bound publication with revoked, stale, invalid or unavailable evidence, regressive time/epoch, or route change without epoch increment closes immediately, even if same tick. Malformed authoritative input or exception closes; untrusted callers must never hold operator capability.
- A valid newer bound positive publication can refresh the current snapshot atomically, with monotonic time/revision/epoch. Operator observeFence supplies CURRENT fixture freshness, not delayed transport: exact matching actor/operation/time/revision/epoch confirms the existing snapshot; changed or regressive bound coordinates, unknown/malformed input close. A valid unrelated fence is rejected. Explicit withdrawal at higher revision remains terminal. On source outage the operator must call observeFence(null) immediately; no background clock or propagation implied.
- Terminal closure clears the positive reference; no later publish or fence observation reopens that instance. Fresh authoritative seeding is required for a new instance; real anti-rollback, authentication, clock and generation persistence are not implemented. This conservative same-tick model prioritizes denial over stale allow; no automatic regrant, fallback, wall-clock timer, or production adapter. Live server must independently obtain authenticated principal, current time/fence and consistent authoritative evidence at decision/transaction time. A fixture operator can lie; this is capability separation, not a security boundary against a compromised process.
