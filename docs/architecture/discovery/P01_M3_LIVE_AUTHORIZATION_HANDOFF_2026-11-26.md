# M3 live authorization approval handoff

**Prepared. Approval and execution pending.** The [canonical Wave 1 M3 packet](../wave-1/IDENTITY_R5_M3_PRODUCTION_CANARY_APPROVAL_PACKET.md) governs. This handoff records the approvals required on the revision 20 baseline. It does not advance M3, authorize production reads, grant IAM or authorize cutover. Approvals for P01.2 metadata or P01.5 bounded data do not authorize M3.

| Approve metrics, if selected | Reliability/Finance Owner | Exact usage window and aggregate SDK read/denial counters. Review access to authoritative metrics separately, leave billed usage unverified if unavailable or unattributable. |

**Procedure after approvals.** Confirm current deployed candidate and held ledger/Rules, review the canonical packet exclusions and verified offline evidence at the actual pin. Re-run source preflight or corresponding tests only if the checked source changed. The actor opens a legitimate approved session and uses only an operator-reviewed server-forced point read for each exact allowed/denied target. The proposed point-read cap is **24 attempts total**, two per actor and zero retries. Authentication operations are accounted for separately. No app bootstrap, callables, unbounded queries, listeners, debug traces, token sharing or write probes. An expected denial must return `permission-denied`. Missing, timeout, expiry and network failures are inconclusive. Any unexpected grant or drift stops the run and escalates to Security. Canonical sampler evidence is a separate axis, capped and stop-on-overflow, with its own explicit approval and reviewer.

Report allow/deny/inconclusive by role and scope, canonical source and freshness evidence, operations, exclusions and unresolved outcomes. No names, paths, contents, raw logs, credentials or customer data in reports or Git. The independent reviewer signs outcome and residual risks before any milestone decision. An emulator pass does not sign actor approval. No Rules/reader/sampler cutover, mutation, deployment or final exit is authorized.
