# R13 scope freeze

Brick 13 is frozen for CI around one product decision: add a governed interactive sound/word utility to the existing phonics hub without creating individual indexable word pages.

Any future mass word-page publication, A–Z browse pages, sound-count browse pages, word schemas, whole-word audio, or broad reading-knowledge expansion belongs to later bricks and must not be smuggled into R13 merely to increase page count.
