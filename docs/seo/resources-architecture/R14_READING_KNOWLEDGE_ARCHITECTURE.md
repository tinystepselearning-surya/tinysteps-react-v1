# Resources R14 — Reading Knowledge Architecture & Content Audit

Revision: `2026-09-09-r14`

## Purpose

R14 turns the existing Tiny Steps reading/phonics editorial library into a governed knowledge system before more articles are added.

The goal is **not** to mass-rewrite blogs or imitate another literacy website. It is to:

1. make the main reading-skill domains explicit;
2. preserve existing canonical owners;
3. separate spoken-sound awareness from print-based phonics;
4. identify only genuine high-value gaps;
5. classify future work as `KEEP`, `REFRESH`, `CONSOLIDATE`, or `CREATE`;
6. prevent keyword-led duplicate articles.

## Editorial architecture

R14 models nine interacting domains:

1. Oral Language & Listening
2. Phonological Awareness
3. Phonemic Awareness
4. Phonics & Decoding
5. Word Recognition
6. Reading Fluency
7. Vocabulary
8. Reading Comprehension
9. Spelling & Encoding

This is **not a rigid developmental staircase**. The domains interact. Phonemic awareness is the phoneme-level part of phonological awareness, and phonics is where speech sounds are explicitly linked with print.

## Useful ideas retained from external reference review

The following sites were reviewed as **information-architecture and parent-communication references**, not as text to copy and not as the final evidence authority for Tiny Steps scientific claims:

- Read Naturally — clear separation of reading components and phonological/phonemic-awareness concepts.
- Reading Rockets — strong parent-facing oral-sound vs print distinction and observable skill examples.
- National Literacy Trust — concise definition → example → teaching/help progression.
- Jolly Phonics — easy-to-understand presentation of a teaching sequence and practical next steps.

Tiny Steps keeps only the parts that improve parent usefulness or editorial architecture. Scientific claims should continue to be supported by primary research, government guidance, evidence syntheses, or other authoritative sources where appropriate.

## Canonical ownership protection

R14 does not replace the Brick 5 canonical ownership system. Where an R14 audit record references an existing canonical topic ID, the R14 audit verifies that the owner path still matches the established registry.

Examples preserved:

- phonics definition → `/blog/what-is-phonics-for-kids`
- broad parent phonics guide → `/blog/phonics-for-parents-guide`
- blending progression → `/blog/how-kids-learn-blending`
- ABC-known reading failure → `/blog/child-knows-abc-but-cannot-read`
- letter-sounds-known word-reading failure → `/blog/why-child-knows-letter-sounds-but-cannot-read-words`
- CVC explanation → `/blog/cvc-words-explained-for-parents`
- fluency guide → `/blog/how-to-improve-reading-fluency-in-children`

The three CREATE candidates are intentionally **not** added to the public route manifest, SEO registry, sitemap, LLM files, or canonical ownership registry in R14.

## Relationship to R13

R13 supplies the sound/word utility layer. R14 provides the broader reading knowledge context around that utility.

Example conceptual boundary:

- hear and manipulate `/sh/ /i/ /p/` without print → phonemic awareness;
- map `sh | i | p` to speech sounds → phonics;
- blend the mapped sequence into `ship` → decoding;
- recognise `ship` rapidly after secure experience → word recognition;
- read it accurately in connected text → fluency;
- understand the word and sentence → vocabulary/comprehension.

R14 does not alter R13 word analyses or publish word URLs.
