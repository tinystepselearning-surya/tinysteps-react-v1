## Rules

1. Subject hubs link to these owners; they do not reproduce the owners' full explanations.
2. Existing `/blog/*`, commercial, parent, school, and game URLs are not moved.
3. Subject-hub titles avoid commercial `classes` intent.
4. No new granular topic URL is allowed merely because a hub needs another card.
5. Programmatic or pattern-level URLs require a later ownership/query-demand audit before publication.
