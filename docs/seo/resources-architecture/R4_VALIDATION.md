# Brick 4 Validation Gate

Before merge, the Brick 4 PR must pass:

- Resources R4 Subject Hubs workflow;
- Resources R3 Navigation regression;
- Resources R2 Learning Hub regression;
- Resources R1 Semantic Facts regression;
- Resources R0 Safety Baseline;
- GSC Content Quality & Consolidation Guard;
- GSC Revalidation & Submission Plan;
- SEO Crawl & Discovery Guard;
- SEO Dead URL Guard;
- full repository lint, typecheck, unit tests, production build/prerender, and SEO smoke.

The subject routes must render as self-canonical, indexable, prerendered CollectionPage-style discovery hubs and appear in the generated sitemap. Existing programme and editorial owners must remain unchanged.
