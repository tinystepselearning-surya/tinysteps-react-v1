# Brick 4 Build Scope

Brick 4 publishes only these new public subject routes:

- `/resources/phonics`
- `/resources/grammar`
- `/resources/speaking`

It does not publish programmatic SEO pages, move any `/blog/*` URL, or change the ownership of `/phonics`, `/grammar`, `/speaking`, `/parents`, `/for-schools`, `/free-english-games-for-kids`, pricing, comparison, or assessment pages.

The three subject hubs are discovery/orchestration pages built around existing canonical owners. Their primary navigation model is Learn the pathway → Practise the skill → Solve a problem, with programme and assessment actions presented separately as secondary next steps.
