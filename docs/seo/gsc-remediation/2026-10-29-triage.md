# GSC exclusion triage — 29 October 2026

## Scope and evidence

This is a diagnostic-only PR. It changes no live website SEO, redirects, robots, sitemaps, hosting or indexing submissions.

Owner-supplied Google URL Inspection API data for the Tiny Steps domain: 395 repository-known routes, 267 intended-index routes, 222 indexed, 13 Soft 404, 10 crawled/not indexed, 10 discovered/not indexed, 7 reported noindex, and 5 unknown. Zero registry/sitemap mismatches.

The API reports Google's stored index data, NOT live URL tests. All 267 intended-index URLs received final valid Google responses. Google last-crawl date matters: seven noindex reports are from July/August, while several Soft 404 results are from October 26–29. Cached public web snapshots are not current live HTTP evidence.

## Read-only verification

Use a clean worktree on this branch, then run:

    npm ci
    npm run test:gsc-live-spotcheck
    npm run seo:gsc-live-spotcheck -- --live --include-controls

After an ordinary production build you may compare static output:

    npm run seo:gsc-live-spotcheck -- --dist --include-controls

The check tests direct response code, redirects, HTML content type, canonical, robots directives in HTTP headers and HTML, h1 and initial body text. Local output: artifacts/gsc-live-spotcheck.json or artifacts/gsc-dist-spotcheck.json, both ignored. There is no credential requirement and no site write. A network failure is not a crawl error. A pass does not prove indexing.

## Remediation gate

- For recent Soft 404, compare actual live initial HTML against prerendered dist output and inspect GSC Test Live URL rendered HTML before changing page content or redirects.
- For historical noindex, confirm live meta and HTTP directives plus Googlebot live rendering before altering indexing policy.
- For age-specific phonics pages, check differentiated age-specific purpose, links, and canonical. Avoid synthetic content merely to force indexing.
- For discovery issues, check deployed sitemaps and useful internal links; absence from the Google-reported sitemap field alone is not proof of sitemap exclusion.
- For crawled/not indexed, technical indexability alone does not guarantee Google's index selection.
- No sitewide rewrites, forced indexing requests or production deployments are authorized by this diagnostic PR.

GSC read-only API tooling is separately tracked in draft PR #821. The owner retains the detailed 45-row CSV and raw inspection JSON locally.
