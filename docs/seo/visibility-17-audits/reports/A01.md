## 1. Executive verdict
The publicly indexed/retrievable **web search result** for the homepage presents a coherent online education brand, ages 3–12, four subject pathways, skill-led placement, parent updates, and a free 35-minute 1:1 assessment CTA. A second web retrieval gave an older/different homepage extract, demonstrating that external snapshots are not a reliable present-day DOM/version comparison. GitHub main implements canonical metadata, WebPage/Organization/WebSite/FAQ structured-data construction and homepage programme links, but deployed head tags, actual HTTP response headers and execution of structured-data scripts were not independently confirmed. The research **does not establish whether Google or Bing has currently indexed the homepage**, nor how it ranks, nor whether it is cited by a native AI answer engine. No P0 production block is reproduced; material trust and CTA-verification candidates remain open.

**Confirmed:** externally retrievable homepage content in web-search layer; programme/assessment claims in source and external extracts; third-party Trustpilot profile; index-permissive bots policy in repository. **Unverified:** HTTP status and redirect chain; deployed canonical/noindex and JSON-LD; sitemap inclusion from actual deployed XML; direct Google/Bing native SERPs, GSC/BWT; actual WhatsApp handoff; named academic credentials and substantiation for learner/country totals.
