## 1. Executive verdict

The latest available public search retrieval of /curriculum (reported crawled 2026-10-16) and inspected main component agree on four connected, skill-led learning pathways: phonics, reading, grammar/sentence building, and speaking/communication. The current main component explicitly disclaims formal CBSE/ICSE/IB/Cambridge affiliation; this is a material credibility improvement over an older cached version using “Cambridge-aligned.” However, the public retrieval system also exposes older /curriculum and query-parameter snapshots with three pathways and prior alignment wording; this is a version/freshness **investigation candidate**, NOT proof of current live contradictory HTML. No native AI citation, current Google/Bing rank, GSC inclusion, Bing index inclusion, production HTTP response code, raw response headers, Core Web Vitals, sitemap membership or deployed structured-data JSON was independently verified. **No P0/P1 live defect is proven.**

Confirmed source strengths: separately described phonics/reading outcomes; non-age-only placement; educational distinction between curriculum and teacher method; actionable course links; route-specific title/canonical metadata and JSON-LD generators.
