## 1. Executive verdict

The Free English Games hub is discoverable in the web page reader and provides a real 7-stage catalogue with **14 labelled playable tiles out of 35 listed tiles**: five letter/sound, five word-building, one sentence, two reading, one grammar and **zero speaking or championship** activities. Each of its seven category URLs and eleven public-specific/standalone game URLs returned readable page representations (20 unique URLs including hub); all 20 are in the checked-in static sitemap and source route manifest. The implementation contains seven publicly embeddable generic guest game engines, three special game pages, and the separate Vocabulary Adventure shell. This is strong evidence of a real public offering, **not proof of functioning round completion on live mobile devices**, exact current origin status, search indexation, or AI recommendation.

**Most actionable verified observations:** 1) marking a ready game 'Completed' is a manual browser-local toggle, not verified learning success (A13-F001); 2) browser progress text is ambiguous against persistent localStorage (F002); 3) the main hub does not say tracing is only free A–N although the tracing landing discloses the O–Z paid option (F003); 4) public speaking games are not yet playable and the discoverable speaking game shell has no in-browser game (F004, linked to **A07-F001**); 5) four word-building tiles share an undifferentiated public start (F005); 6) a precise learning-timeframe statement and source audio/wording mismatches merit review (F006/F007).

**No verified P0 or live P1 technical outage** is established. Origin canonical/noindex, live XML/robots, successful audio/touch/keyboard, child privacy/analytics transmission, paywall unlocking, first-party Google/Bing inclusion and native AI citation are **UNVERIFIED**. A cached three-month-old game landing is not proof current deployment serves old content.

**Ownership:** A13 owns **game readability/readiness/instructions/activity pathways**; A07 owns the general resource gateway speaking-game pointer (A07-F001); A10 owns the Vocabulary knowledge pathway (A13 owns free-game shell behavior only); A03/A04/A05/A06 own programme pages; A15 editorial blog QA; A16 demo/paid entitlement/WhatsApp purchase and parent conversions; A17 technical/sitewide/robots/sitemap and search reconciliation.
