# Tiny Steps AI Visibility Query Tracker

Canonical domain: https://tinystepslearning.com

## Purpose
This file lists manual test queries to check whether Tiny Steps is discoverable, accurately described, and positively represented across AI search engines and answer engines.

## How to Test
1. Open ChatGPT, Perplexity, Gemini, Claude, Google Search with AI Overviews, and Bing Copilot.
2. Search 5–10 queries from each category every 2 weeks.
3. Record whether Tiny Steps appears, whether the description is accurate, and whether competitors are mentioned.
4. Save screenshots or notes separately.
5. Use the results to decide which pages need better content, schema, reviews, internal links, or third-party mentions.
